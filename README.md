# Проект Coursework

## Описание

Проект представляет собой веб-приложение, разработанное с использованием современного стека технологий. Приложение разделено на frontend и backend части для обеспечения масштабируемости и удобства разработки.

## Структура проекта

### Frontend

- React + TypeScript + Vite
- Современная FSD архитектура
- Prettier и ESLint для поддержания качества кода

### Backend

- Node.js + TypeScript
- Prisma ORM для работы с базой данных
- Структурированная архитектура (controllers, services, routes)
- Поддержка загрузки файлов (avatars)

## Требования

- Node.js (рекомендуется последняя LTS версия)
- Yarn (пакетный менеджер)
- База данных (согласно конфигурации Prisma)

## Установка и запуск

### Backend

1. Перейти в директорию backend:

```bash
cd backend
```

2. Установить зависимости:

```bash
yarn
```

3. Настроить переменные окружения:

- Создать файл .env
- Добавить необходимые переменные окружения (Можно посмотреть .env.example)

4. Выполнить миграции базы данных:

```bash
yarn prisma migrate dev
```

5. Запустить сервер:

```bash
yarn dev
```

### Frontend

1. Перейти в директорию frontend:

```bash
cd frontend
```

2. Установить зависимости:

```bash
yarn
```

3. Запустить development сервер:

```bash
yarn dev
```

## Дополнительная информация

- Для загрузки аватаров используется директория backend/uploads/avatars
- В проекте используется кастомный шрифт DejaVuSans
- Конфигурация TypeScript разделена на несколько файлов для оптимизации разработки
