# SkillHorizon

## Описание

SkillHorizon - это платформа для создания и прохождения онлайн-курсов. Проект разделен на frontend и backend части для обеспечения масштабируемости и удобства разработки.

## Технологии

### Frontend

- React + TypeScript
- Vite как сборщик
- Ant Design как UI библиотека
- React Router для маршрутизации
- SCSS модули для стилизации
- Zustand для управления состоянием
- React Query для кэширования

### Backend

- Node.js + TypeScript
- Express.js как веб-фреймворк
- Prisma как ORM
- PostgreSQL как база данных
- JWT для аутентификации
- Multer для загрузки файлов

## Установка и запуск

### Backend

1. Перейти в директорию backend:

```bash
cd backend
```

2. Установить зависимости:

```bash
pnpm install
```

3. Настроить переменные окружения:

- Создать файл `.env` на основе `.env.example`
- Указать необходимые переменные окружения:
  - `DATABASE_URL` - URL для подключения к PostgreSQL
  - `JWT_SECRET` - секретный ключ для JWT
  - `JWT_REFRESH_SECRET` - секретный ключ для JWT refresh токенов
  - `SERVER_URL` - URL сервера
  - `PORT` - порт для запуска сервера (по умолчанию 3000)

4. Выполнить миграции базы данных:

```bash
pnpm prisma migrate dev
```

5. Запустить сервер:

```bash
pnpm dev
```

### Frontend

1. Перейти в директорию frontend:

```bash
cd frontend
```

2. Установить зависимости:

```bash
pnpm install
```

3. Настроить переменные окружения:

- Создать файл `.env` на основе `.env.example`
- Указать `VITE_API_URL` - URL бэкенд API

4. Запустить development сервер:

```bash
pnpm dev
```
