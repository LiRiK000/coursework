# Анализ фронтовой части приложения

## Архитектура

Приложение построено с использованием современного стека технологий:

- React + TypeScript
- Vite как сборщик
- Ant Design как UI библиотека
- React Router для маршрутизации
- SCSS модули для стилизации

### Структура проекта

Приложение построено по методологии Feature-Sliced Design (FSD). FSD был выбран по следующим причинам:

1. Масштабируемость

   - Четкая структура для роста приложения
   - Изолированные модули легко расширять
   - Простое добавление новых фич

2. Переиспользуемость

   - Строгая изоляция компонентов
   - Четкие границы между слоями
   - Минимизация дублирования кода

3. Независимая разработка

   - Команда может работать параллельно
   - Каждый слой имеет свою зону ответственности
   - Меньше конфликтов при мерже

4. Удобство поддержки
   - Понятная навигация по проекту
   - Предсказуемая структура
   - Упрощенный рефакторинг

Структура приложения разделена на следующие слои:

```
frontend/
├── src/
│   ├── app/                 # Инициализация приложения
│   ├── pages/              # Страницы приложения
│   ├── widgets/            # Композиционные компоненты
│   ├── features/           # Функциональные модули
│   ├── entities/           # Бизнес-сущности
│   ├── shared/             # Переиспользуемые компоненты и утилиты
│   └── main.tsx           # Точка входа
```

## Основные модули

### Аутентификация

- Управление состоянием авторизации
- Защищенные маршруты
- Интеграция с JWT

### Курсы

- Отображение списка курсов
- Детальная информация о курсе
- Управление избранными курсами
- Создание и редактирование курсов

### Пользователи

- Профиль пользователя
- Управление настройками
- История обучения

### Тесты

- Создание и редактирование тестов
- Прохождение тестов
- Оценка результатов

## Компоненты

### CourseCard

Карточка курса с основной информацией:

- Обложка курса
- Название и автор
- Категория и уровень
- Кнопки действий (избранное, удаление, прохождение)

### CreateCourse

Форма создания/редактирования курса:

- Название курса
- Описание курса
- Создание секций (блоков) курса
- Предпросмотр

### CreateTest

Форма создания/редактирования теста:

- Вопросы с вариантами ответов
- Настройка правильных ответов
- Управление процентом для успешного прохождения
- Предпросмотр
