# User Cases для SkillHorizon

## Для студентов (US1-US20)

US1: Авторизация через email/пароль → Главная → Выбор курса → Начало обучения

- Frontend: Модалка авторизации, роутинг /courses
- Backend: POST /auth/login, GET /courses

US2: Прохождение интерактивного теста с "кол-вом жизней" → Результат → Сохранение прогресса

- Нужен: Компонент для тестирования с "жизнями", хранилище прогресса
- API: POST /tests/{id}/submit

US3: Мобильная оптимизация курсов → Адаптация интерфейса → Тестирование на устройствах

- Компоненты: Все что с кликом на десктопе -> Touch

US4: Расширенная аналитика → Визуализация прогресса

- Графики: ProgressRadarChart
- API: GET /analytics/compare

## Для авторов (US21-US30)

US1: Создание курса с WYSIWYG редактором → Публикация → Модерация

- Компонент: CourseEditor с draft-сохранениями
- API: POST /courses/drafts

US2: Геймификация обучения → Награды за прогресс → Бейджи в профиле

- Компонент: AchievementBadges
- API: PATCH /users/{id}/achievements

## Для администраторов (US31-US35)

US1: Базовая аналитика активности → Сбор метрик → Экспорт в CSV

US2: Аудит безопасности → Мониторинг входов → Блокировка подозрительных

US3: Принятие пользовательских запросов на авторство → Модерация

US4: Управление пользователями → Создание/редактирование → Блокировка

US5: Управление курсами → Публикация/модерация → Удаление

- API: GET /courses, PATCH /courses/{id}

## Технические требования

### Frontend

- Система ролевой маршрутизации (react-router)
- Глобальное хранилище (Zustand/Jotai)
- UI-кит для форм/тестов

### Backend

- Модель Course с полями: status (draft/published)
- Мидлвара для проверки ролей
- Сервис генерации сертификатов (PDF)
